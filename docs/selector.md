### x / y / z

- **描述**：选择器执行过滤时的坐标。
- **示例**：
  - x 轴坐标为 3：`x=3`
  - y 轴坐标为 3：`y=3`
  - z 轴坐标为 3：`z=3`
  - x 轴坐标为 1 且 y 轴坐标为 2：`x=1,y=2`
- 支持范围格式，例如 `x=1..3`
- **开发要求**：推荐用字符串

### dx / dy / dz

- **描述**：坐标偏移量，用于选择指定坐标范围内实体。
- **示例**：
  - x 轴偏移 3 格：`dx=3`
  - y 轴偏移 3 格：`dy=3`
  - z 轴偏移 3 格：`dz=3`
  - y 轴偏移 -1 格，z 轴偏移 2 格：`dy=-1,dz=2`
- **开发要求**：推荐用字符串

### type

- **描述**：实体类型，**可反选**。可用值列表见 "实体 ID"。
- **注意**：多个非反选 type 放在一起则会出错。
- **示例**：
  - 实体类型为僵尸：`type=zombie`
  - 实体类型非僵尸：`type=!zombie`

### name

- **描述**：实体名称（亦可用于掉落物）。**可反选**。
- **示例**：
  - 名字为 xlwt 的实体：`name="xlwt"`
  - 名字不为 xlwt 的实体：`name=!"xlwt"`
  - 未命名的实体：`name=""`
  - 已命名实体（含玩家）：`name!=""`
- **开发要求**：是否反选作为一个下拉选择或胶囊开关，后面允许填入字符串，引号自带

### tag

- **描述**：标签，**可反选**。不是玩家名称。
- **版本说明**：添加或移除标签需使用 tag 命令（**仅基岩版** 或 Java1.13+）或 /scoreboard players tag ...（仅Java1.12-）。
- **示例**：
  - 拥有标签 "a" 的实体：`tag=a`
  - 没有标签 "a"：`tag=!a`
  - 所有有任意标签的实体：`tag=!`
  - 所有没有任何标签的实体：`tag=""`
- **开发要求**：类似 name，是否反选作为一个下拉选择或胶囊开关，后面允许填入字符串，不自带引号

### r (最大半径)

- **描述**：可选定以 r 的值为半径的球体中的实体。
- **可用值**：0(含)~340282356779733661637539395458142568448(不含)
- **示例**：
  - 最大半径为 10 `r=10`
  - 支持范围，例如 `1..10`
- **开发要求**：推荐用字符串

### rm (最小半径)

- **描述**：用 rm 选择器可选定以 rm 的值为半径的球体以外符合条件的实体。
- **可用值**：0(含)~340282356779733661637539395458142568448(不含)
- **示例**：
  - 最小半径为 10 `rm=10`
  - 支持范围，例如 `1..10`
- **开发要求**：推荐用字符串

### scores (计分板分数)

- **描述**：基于计分板分数的筛选。
- **示例**：
  - 计分板 a 分数为 1：`scores={a=1}`
  - 计分板 a 的分数≥1：`scores={a=1..}`
  - 计分板 a 的分数≤1：`scores={a=..1}`
  - 计分板 a 中有分数记录且≠1：`scores={a=!1}`
  - 计分板 a 的分数在 1 至 2 之间(含)：`scores={a=1..2}`
  - 多个计分板：`scores={a=1..2,b=!2..10}`
- **开发要求**：直接提供 `{}` 内部的完整编辑功能，让用户自己编辑内部，例如填 `a=1..` `a=!..1` `a=1,b=2`，我们不干预。

### C (选择数量/顺序)

- **描述**：选择顺序和最大选中数量。
- **用法**：
  - 正整数选择由近到远的实体，负整数选择由远及近的实体。
  - 对于 `@` 选择器类型，此参数将决定其会随机选中多少个符合条件的实体。
- **可用值**：-2147483648~2147483647 整数(不含 0)
- **示例**：最多选择 3 个最近实体 `c=3`
- **开发要求**：推荐用字符串

### l (最大经验等级)

- **描述**：最大经验等级。
- **可用值**：-21474483647 整数
- **示例**：经验等级≤10 级的玩家 `l=10`
- **开发要求**：推荐用字符串

### lm (最小经验等级)

- **描述**：最小经验等级。
- **可用值**：0~2147483647 整数
- **示例**：经验等级≥10 级的玩家 `lm=10`
- **开发要求**：推荐用字符串

### m (游戏模式)

- **描述**：游戏模式，**可反选**。
- **示例**：游戏模式为生存模式的玩家 `m=0`
- **可用值**：
  - 生存模式 survival 或 0 或 s
  - 创造模式 creative 或 1 或 c
  - 冒险模式 adventure 或 2 或 a
  - 默认模式 default 或 d
  - 旁观模式 spectator
- **开发要求**：下拉菜单选择，只提供完整英文单词，不提供简写

### rx / ry (最大旋转角度)

- **描述**：最大垂直/水平旋转角度。rx 为垂直，ry 为水平角度。
- **示例**：
  - 抬头：`rx=-89`
  - 小于等于正南：`ry=0`
- **部分特殊水平角度**：0 正南，-180/180 正北；-90 正东，90 正西。
- **开发要求**：推荐用字符串

### rxm / rym (最小旋转角度)

- **描述**：最小垂直/水平旋转角度。rxm 为垂直，rym 为水平角度。
- **示例**：
  - 低头：`rxm=89`
  - 大于等于正南：`rym=0`
- **开发要求**：推荐用字符串

### family (家族/族)

- **描述**：选择属于/不属于指定族的实体。**可反选**。
- **示例**：选择敌对生物 `family=monster`
- **开发要求**：用字符串

### hasitem (持有物品)

- **描述**：选择在指定槽位拥有指定物品的实体。使用大括号包含所有参数，其中每个参数间使用英文逗号分隔。参数格式为 `参数=值`。若检测多个物品，使用中括号包括它们。
- **可用参数**：
  - `item`: 物品 ID
  - `data`: 物品数值(选填)
  - `location`: 槽位 ID(选填)
  - `slot`: 槽位数值(选填)
  - `quantity`: 物品数量(选填)
- **示例**：
  - 选择手持 1 个火把的玩家：`hasitem={item=torch,data=0,location=slot.weapon.mainhand,slot=0,quantity=1}`
  - 选择手持 1~3 个火把并佩戴海龟壳的玩家：`hasitem=[{item=torch,data=0,location=slot.weapon.mainhand,slot=0,quantity=1..3},{item=turtle_helmet,data=1,location=slot.armor.head,slot=0,quantity=1..3}]`
- **开发要求**：这是最复杂的一个，需要嵌套的编辑器，可以参考T显编辑器的翻译键那个元素。内部嵌套编辑的就是可用参数部分。

### haspermission (权限)

- **描述**：选择指定权限已启用/已禁用的玩家。如检测多项权限，则在同一大括号内使用英文逗号分隔每个权限参数。
- **“权限”可用值**：
  - `camera`: 视角转动权限
  - `movement`: 位置移动权限
- **“值”可用值**：`enabled` (启用); `disabled` (禁用)。
- **格式**：`{权限=值}` 或 `{权限=值,权限=值,以此类推}`
- **开发要求**：自带 `{}`，内部嵌套编辑器，用多级的复选下拉菜单选择权限（推荐级联选择 Cascader组件），允许两项权限都选，但是每项权限的允许/禁用互斥。类似：
  视角转动 > 允许 禁用
  位置移动 > 允许 禁用

### has_property (属性)

- **描述**：筛选实体的指定属性。可检测有/没有指定属性，或指定属性的对应值是否符合要求。具体属性列表由游戏行为包决定。
- **示例**：
  - 存在指定属性：`has_property={property=属性名}`
  - 缺少指定属性 (反选)：`has_property={property=!属性名}`
  - 拥有指定属性 (可堆叠 逗号分隔)：`has_property={属性名=值,以此类推}`
- **注意**：对于数字值，可通过 ".." 指定范围，用法与 scores 参数一致。
- **开发要求**：自带 `{}`，直接提供 `{}` 内部的完整编辑功能，让用户自己编辑内部，我们不干预。

### 自定义

- **描述**：允许自定义参数
- **示例**：输入栏 = 输入栏，允许随便填。
