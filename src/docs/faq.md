# 常见问题

## 1. 访问本站/卡片的链接打不开

1. 确定网址正确，多刷新几次
2. 更换网络环境：wifi 换流量，流量换 wifi，还不行尝试更换 DNS 或使用代理。
3. 过几十分钟再试：尤其在下午和晚上高峰期时。

---

## 2. 访问本站/卡片的链接跳转无关网站

**现象描述：** 部分用户在访问本站时，可能会遇到以下情况：

- 浏览器未显示本站内容，而是**直接跳转（重定向）** 到了与本站完全无关的广告页面、推广页面，甚至不良信息网站。
- 浏览器地址栏中的 URL 已变为另一个陌生域名。
- 刷新页面、清除缓存后问题依旧；但换用其他网络（如手机移动数据）访问则一切正常。

**本站郑重声明：<u>本站不投放任何弹窗广告，更不存在任何形式的自动跳转逻辑，也从未授权任何第三方进行流量转发。上述现象与本站无关</u>**。

---

**解决方案：**

- **始终使用 HTTPS 访问本站。** 请确认地址栏以 `https://` 开头且显示安全锁标志。HTTPS 的 TLS 加密可有效防止中间人伪造响应内容。
- 更换网络环境：
  1.  wifi 换流量，流量换 wifi，或更换不同运营商 (尤其是**福建移动**，DNS 污染非常严重，目前收到的反馈超9成来自福建移动)
  2.  尝试更换 DNS 解析服务器，并启用安全 DNS（DoH / DoT）
  3.  使用代理
- 如果确认问题出在宽带运营商侧，且你愿意花时间推动解决，建议按以下路径逐级反馈：
  1. **联系你的宽带运营商**
     - 拨打对应客服热线（电信 10000 / 联通 10010 / 移动 10086），转人工或技术支持。
     - 清晰描述现象："访问某域名时，被网络中间节点返回了伪造的 HTTP 重定向响应，跳转至无关广告/不良网站。"
     - 要求对方排查本地 DNS 及透明代理/网关设备，并记录工单号。
  2. **向电信行业监管部门申诉**
     - 若**运营商未能有效解决**，可通过 **工业和信息化部电信用户申诉渠道**（微信搜索"工信部 12300"小程序，或访问工信部政务服务平台）提交申诉。
     - 也可向所在省份的 **通信管理局** 反映情况。

## 3. 网址记不住怎么办？

1. **收藏夹**：浏览器收藏夹里保存一份，想用的时候直接点开。
2. **[o3o.ren/tool](https://o3o.ren/tool)：**"欧三欧点人(ren)/工具(tool)"，这样总能记住了吧？

## 4. 我的数据存在哪里？

所有个人配置（收藏卡片、主题偏好、编辑记录等）均存储在浏览器的 [localStorage](https://developer.mozilla.org/zh-CN/docs/Web/API/Window/localStorage) 中，不会上传到任何服务器。

> **注意：** 清除浏览器数据或使用无痕模式可能导致配置丢失，建议定期通过 [设置页](/settings) 导出配置备份。

---

## 5. 有 App 吗？

有。本站支持 PWA 安装，在侧边栏选择“安装”，之后就能像普通 App 一样打开使用。

> ⚠️ 需要系统和浏览器支持，推荐使用标准浏览器，例如 Chrome、Edge、Safari、Firefox、系统自带浏览器等，非常不推荐百度等瞎\*\*改的浏览器

---

## 6. 能离线使用吗？

部分支持。静态页面和已缓存的资源在离线时仍可访问，但依赖网络的工具（如在线搜索、下载解析等）需要联网。完全离线时会显示诊断页提示当前状态。
