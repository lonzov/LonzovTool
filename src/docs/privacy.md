# 隐私政策

**更新日期：** 2026年11月20日　**生效日期：** 2026年11月21日

小舟工具箱（`tool.lonzov.top`，下称“本网站”或“我们”）是一个 Minecraft 工具导航站。浏览公开页面无需注册；表单和控制台由我们自建的后端处理，控制台仅限授权人员使用。

本政策说明我们处理哪些信息、为什么处理、与谁共享、保存多久，以及您可以如何管理。我们不会出售或出租您的个人信息，也不会将其用于广告画像。

## 一、适用范围

本政策适用于您访问和使用 `tool.lonzov.top` 时产生的个人信息处理活动。运营者为“小舟工具箱”（站长：浪小舟）。

本站链接、站外 iframe、嵌入的第三方内容（如视频播放器）以及下载的第三方资源，属于第三方网站，不是本网站的服务商；它们是否设置 Cookie、如何处理数据，适用其自身隐私政策，不属于本政策范围。

## 二、我们处理的信息

我们只处理实现功能所必需的信息，主要包括：

- **访问技术信息**：IP、访问时间、URL、User-Agent、Referer、HTTP 状态码等，用于安全审查、故障排查、反滥用和基本访问统计。
- **表单信息**：您在表单中主动填写或上传的联系方式、文本、图片等，用于审核、处理和回复。部分内容经审核后可能公开展示，反馈及其图片仅供授权人员处理。请勿提交身份证、面部、住址、账号密码等敏感信息。
- **安全信息**：IP、User-Agent、人机验证结果、短期访问计数和安全日志，仅用于安全防护与审计。
- **控制台账号信息**：不适用于普通访客，详见第六节。

以下服务属于**不可关闭的必要服务**：

- **Umami Analytics**：由我们自行部署，统计数据由我们保管，不流向 Umami 官方或第三方平台。
- **Cloudflare Web Analytics**：Cloudflare 提供的访问与性能统计，仅对非欧盟/英国地区用户启用。
- **Cloudflare 边缘安全防护**：Cloudflare 的 CDN、防火墙、机器人识别和访问挑战等安全功能。

Umami 和 Cloudflare Web Analytics 只做匿名统计：不使用 Cookie 或 localStorage 保存统计标识，不收集姓名、邮箱、账号等直接身份信息，不跨站追踪，不建立个人画像，不用于广告；统计结果为聚合数据，我们无法据此定位具体个人。

以下统计默认关闭，您可以在隐私偏好中开启：

- **51.la**：访问统计，可能记录 IP、访客标识、设备信息和访问路径。
- **Umami 会话回放**：默认关闭，抽样录制并限制单次时长，页面文字和输入内容在浏览器端遮蔽，约 7 天后删除。

## 四、Cookie 与本地存储

本站设置的必要 Cookie 仅用于控制台登录、登录状态保持和 CSRF 防护。Cloudflare 边缘安全防护也可能设置其必要的安全 Cookie；51.la、极验、Turnstile 等服务以及站外嵌入内容在加载时可能设置各自的 Cookie。您可以清除或阻止这些 Cookie，但可能影响登录、验证等功能。

本站使用浏览器本地存储保存个性化设置、隐私偏好、表单草稿和缓存等网站数据。这些数据保存在您的设备上，本网站不会主动上传；您点击提交表单时，表单内容会发送到后端。您可以在浏览器中清除本站的网站数据，清除后可能丢失设置、草稿和登录状态。

首次访问时的隐私提示条提供两种选择：

- **接受全部**：开启 51.la 和 Umami 会话回放；
- **管理偏好**：分别选择是否开启 51.la 和会话回放；两项都关闭时只启用必要服务。

必要服务无法关闭；51.la 和会话回放默认关闭，可随时通过提示条或设置页的“隐私偏好”调整。关闭 51.la 后不再加载其脚本；关闭回放后不再录制，已录制数据在保留期到期后删除。

## 五、保存期限

| 数据                                        | 保存期限与到期处理                                                                                            |
| :------------------------------------------ | :------------------------------------------------------------------------------------------------------------ |
| 表单中的联系方式、IP、User-Agent 等直接标识 | 默认 180 天后清除；表单正文继续保留                                                                           |
| 表单中的图片                                | 反馈截图 180 天后删除；投稿图标随投稿记录保留，审核通过后作为卡片素材公开展示                                 |
| 管理日志                                    | 普通信息默认 90 天，警告/错误默认 365 天                                                                      |
| 控制台会话 / 信任设备                       | 会话约 12 小时，信任设备约 30 天                                                                              |
| 统计服务                                    | Umami 聚合统计长期保留；回放约 7 天；51.la 明细按其政策约 3 周                                                |
| 服务器与边缘日志                            | Cloudflare 按自身政策短期保留；源站日志用于安全审查、故障排查和反滥用，按运维需要不定期清理，一般不超过 90 天 |

180 天到期处理清除的是联系方式、IP、User-Agent 等直接标识，不会删除表单正文。如果正文中包含您主动填写的个人信息，该部分不会自动删除；您可以按第七节申请删除。

## 六、控制台账号（仅授权人员）

本节只适用于控制台授权人员，不适用于普通访客。

控制台账号由运营者创建，不开放公众注册。我们处理的控制台信息包括账号资料、认证凭据、登录信息（登录时间、来源 IP、登录地点、设备和浏览器信息）、审计日志和通知配置，用于身份认证、权限控制、登录安全提醒和安全审计。

控制台账号只停用、不物理删除，以保持审计链完整；停用后凭据失效、不再允许登录。会话约 12 小时过期，信任设备约 30 天过期；登录地点记录在账号存续期间保留，管理日志按第五节期限保留。

## 七、您的权利

您可以联系我们查阅、复制、更正、删除您的个人信息，或撤回对可选隐私偏好的同意。删除表单记录时，我们会删除对应内容和图片；已公开展示的内容如需下架，请一并说明。

对于上述第三方服务产生的数据，本网站无法直接为您提供访问、更正或删除的通道，相关权利行使受对应第三方政策与服务规范的约束。

管理日志等涉及安全审计或法定义务的信息，可能无法立即删除或需要保留至期限届满。已清除联系方式或已聚合的匿名统计，无法再按个人定位。您也可以直接在浏览器中清除本站的 Cookie 和本地存储。

## 八、未成年人保护

本网站面向一般公众，不专门针对未成年人设计。未满 14 周岁的未成年人应在监护人陪同下阅读并在取得同意后使用；不建议未成年人自行打赏或提交联系方式、截图等敏感信息；监护人可联系我们删除相关记录并下架公开内容。

## 九、数据安全

我们使用 HTTPS、Cloudflare 边缘防护、控制台访问控制、加密或哈希存储、私有反馈截图和审计等措施保护信息安全。互联网环境不存在绝对安全，请妥善保管账号和验证设备。

如发生可能影响您的个人信息安全事件，我们会在首页公告，并在可行范围内通过您留下的联系方式告知。

本网站的个性化设置、隐私偏好、表单草稿和缓存等网站数据完全储存在您的浏览器本地，其安全性取决于您的设备、操作系统与浏览器配置。建议您保持浏览器与系统更新，并谨慎使用公共网络环境。

## 十、隐私政策的变更

本政策可能随法律法规要求或网站技术调整而更新。我们将通过以下方式通知重大变更：

- 在网站首页通知栏发布公告
- 若涉及数据处理逻辑的重大变更，提示条将重新出现，提醒您查阅更新后的政策

**更新后的政策将在顶部标注更新日期，建议您定期查阅。**
